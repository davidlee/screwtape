# Screwtape

![img](./screwtape.jpg)

Infernal bureaucrat responsible for mediating access to mail.

Written in Gleam, runs on BEAM, a systemd runner, login to Fastmail via JMAP.

Intended to broker read-only LLM access for summarisation & authoring reviewable, 
auditable execution plans for deterministic invocation by the user.

These systems in aggregate (secure, agentic mail augmentation) constitute Belphegor.
